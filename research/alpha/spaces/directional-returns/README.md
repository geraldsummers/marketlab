# Directional returns

This space asks whether a point-in-time information set improves forecasts of
signed returns or the conditional price distribution. Exact future dollar
prices are represented through returns from the observable decision price.

Existing evidence rejects the current unconditional BTC reversal, narrow
funding-to-return, social-attention return, and development-screened BTC
momentum candidates. It does not reject conditional order-flow, derivatives,
cross-venue, or richer information-interaction mechanisms.

New work must use a fresh candidate ID and untouched confirmation period. It
must distinguish forecast accuracy, executable net return, and portfolio alpha.
